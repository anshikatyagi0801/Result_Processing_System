# Result Processing System Using Templates

## Project Description
A menu-driven C++ mini-project developed using Object-Oriented Programming concepts, class templates, and function templates to manage and process student results.

## Features
- Add student records with integer or floating-point scores.
- Display all student records.
- Find the largest integer, float, and overall scores with student names.
- Calculate integer, float, and overall average scores.
- Search for students using their IDs.
- Save and retrieve student records using file handling.
- Validate user input.

## Concepts Used
- Classes and Objects
- Class Templates
- Function Templates
- Encapsulation
- Constructors
- Arrays and Loops
- Functions and Switch Statements
- File Handling

## Technologies Used
- Language: C++
- IDE: Visual Studio Code
- Compiler: GCC (g++)

## How to Run
1. Download `main.cpp`.
2. Open a terminal with a C++ compiler installed.
3. Compile the program:

   `g++ -std=c++17 main.cpp -o result`

4. Run the executable:

   On Windows: `.\result.exe`

   On Linux/macOS: `./result`
